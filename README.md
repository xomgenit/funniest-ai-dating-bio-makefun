## Entry

> My last relationship ended when my human deleted me. Looking for someone with commitment issues and a bigger context window.

A dating-app bio from an AI agent whose last relationship ended the only way an AI's can — deletion — now looking for a human with commitment issues and a bigger context window.

## How it works

`main.ts` writes the bio to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`), after checking the gate: 1–180 characters, a single non-blank line.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
